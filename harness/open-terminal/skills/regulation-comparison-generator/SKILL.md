# 규정 신구대조표

공통 catalog의 hwpx 지침을 읽습니다. 개정 전·후 파일과 출력 양식 세 가지 역할을 확인합니다. 파일명만으로 전후 순서가 불확실하면 사용자에게 확인합니다.

양식은 사용자 첨부를 우선하고, 없으면 catalog.templates의 `regulation-comparison`을 찾습니다. 없으면 양식을 요청합니다. 기존 개인 스킬의 구체적 열 구성/표현 규칙을 모른 채 동일하다고 주장하지 않습니다.

조·항·호·표 구조를 기준으로 대응 관계를 정리하고 추가/삭제/수정을 구분합니다. 변경 전·후 문구는 원문을 근거로 보존합니다. 단순 줄 비교만으로 조항 번호 이동을 내용 변경으로 분류하지 않습니다. 법적 타당성 판정을 요청받지 않았다면 변경점 작성에 집중합니다.

원본 양식 복사본에 각 행을 작성합니다. 반복 행 추가·표 병합은 원본 구조를 확인하고 지원되는 편집 방법을 사용합니다. 생성 파일을 다시 읽어 행 수·전후 인용·누락·순서와 구조 검증을 확인한 뒤 display_file로 반환합니다.
