# 가정통신문

공통 catalog의 hwpx 지침을 읽습니다. 사용자 첨부 양식이 있으면 우선하고, 없으면 catalog의 templates에서 `family-letter`를 찾습니다. 실제 파일이 없으면 원본 양식을 요청합니다. 경로나 학교 로고·전화번호를 추측하지 않습니다.

제목·일자·대상·행사 내용·준비물·담당부서 등 요청과 근거 자료의 값을 정리합니다. 필수 정보가 없으면 질문하거나 사용자가 허용한 초안 표시로 남깁니다. 본문은 학부모가 이해할 수 있는 안내문으로 작성합니다.

원본을 작업 폴더에 복사하고 누름틀/라벨·표·본문 영역을 조사한 뒤 fill/patch를 사용합니다. 로고·상단/하단 정보·틀을 유지합니다. 본문 길이에 따른 페이지 넘침이나 신청서 표 변경은 별도 확인합니다. 출력 후 내용과 미채움 필드를 검증하고 display_file로 전달합니다.
