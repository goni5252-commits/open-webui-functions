# HWPX 공통 처리

이 지침은 신규 공통 기본 지침이며 기존 학교 개인 스킬의 원문을 복제한 것이 아닙니다. catalog에 학교 override가 등록돼 있으면 해당 지침을 우선 사용합니다.

실제 `kordoc --version`과 필요한 명령의 `--help`를 확인합니다. 버전에 없는 옵션이나 API를 추정하지 않습니다. 기존 설치를 재설치하지 않습니다.
- 읽기/구조 분석: kordoc의 파싱 결과와 원본을 근거로 문단·표·조항을 확인합니다.
- 기존 HWPX 양식: 원본 복사본을 이용하여 fill 또는 patch 기능을 선택합니다. fill은 누름틀/라벨 매칭 실패를 확인하고, patch는 원본 문단·표 구조의 변경 여부를 확인합니다.
- 새 문서: 명시적 학교 양식이 없을 때만 사용자 요구에 맞는 생성 프리셋을 사용합니다. 학교 양식을 기본 프리셋으로 대체했다면 동일 양식을 적용했다고 말하지 않습니다.
- HWP 원본을 HWPX로 이름만 바꾸지 않습니다. 필요한 변환 도구가 없으면 HWPX 원본을 요청합니다.

작업 폴더의 파일에 대해 `kordoc validate <파일.hwpx>`가 설치 버전에서 지원되는지 확인하여 실행하고, 다시 파싱하여 내용·표·미채움 항목을 비교합니다. 구조 검증은 한글 앱의 실제 조판 검증과 다릅니다. 긴 본문·표·페이지 넘김은 렌더링 또는 한글 열람 검증이 필요하며 미실시를 알립니다. 검증된 파일은 display_file로 반환합니다.
